# Open icons and fonts only

Status: accepted

## Context

Windows 11 icons, wallpapers and Segoe UI are Microsoft property and cannot be redistributed under GPL.

## Decision

Icons come from the Fluent UI System Icons font (MIT). The default font is Inter (OFL); `theme.fontFamily` lets users pick any installed font. Wallpapers are the user's own.

## Consequences

Close to the Windows 11 look without license issues.
